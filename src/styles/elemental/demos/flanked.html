Flanked [data-flanked]

Flanked creates a sidebar-plus-content layout. The sidebar targets a width (sidebar:sm|md|lg) while the main content flexibly expands (with flex-grow: 999). When available space drops below the folding threshold (--min-content-width, default 50%), the layout automatically folds into a vertical stack.
